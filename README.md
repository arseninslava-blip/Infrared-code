# RoboCup Junior Soccer — архив кода / code archive

## RU

Архив исходного кода футбольного робота (RoboCup Junior Soccer) за всё время разработки.

- `camera/` — камера OpenMV (Python): поиск мяча, ворот и положения на поле через зеркало.
- `main/` — главная плата (Arduino / PlatformIO): моторы, IMU, тактика атаки и защиты.
- `linesensor/` — датчик линии (Raspberry Pi Pico).

Папки `NN_ГГГГ-ММ-ДД` — версии по порядку, от первых набросков до последних; с 2026-10-17 — из git (последний коммит дня). `current/` — актуальный код.

## EN

Source code archive of a RoboCup Junior Soccer robot, covering the whole development history.

- `camera/` — OpenMV camera (Python): ball, goal and field-position detection using a mirror.
- `main/` — main board (Arduino / PlatformIO): motors, IMU, attack and defense tactics.
- `linesensor/` — line sensor (Raspberry Pi Pico).

`NN_YYYY-MM-DD` folders are versions in order, from the first drafts to the latest; from 2026-10-17 on they come from git (last commit of each day). `current/` holds the latest code.
